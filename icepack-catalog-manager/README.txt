Ice Pack Companion catalog file import patch

1. Stop the Catalog Manager with Ctrl+C.
2. Back up icepack-catalog-manager\public\index.html.
3. Extract this ZIP into C:\IcePackARK\ice-pack-ark\icepack-catalog-manager\ and approve replacing public\index.html.
4. Restart with node .\kit-dashboard.mjs, refresh browser with Ctrl+F5.
5. Export catalog backup, choose the Batch 02 JSON file, click Validate & Import Catalog.

Only public/index.html is changed. Saved Kits and catalogs remain untouched.
